# Password Checker — Beginner Version 1.0

A simple Java console application that validates user passwords based on predefined requirements.

## About the Project

This is one of my first Java projects, created to practice Java Core fundamentals and improve my programming skills.

The application asks the user for their name and then allows them to create a password that meets specific security requirements.

## Password Requirements

A valid password must:

- Contain between 8 and 16 characters.
- Include at least one English letter.
- Include at least one digit.
- Contain only English letters and digits.
- Not be empty.

## Technologies Used

- Java
- IntelliJ IDEA
- Git
- GitHub

## Features

- User input validation.
- Password length validation.
- Character validation using regular expressions.
- Detection of letters and digits.
- Error messages for invalid passwords.
- Repeated password input until valid.

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run `PasswordChecker.java`.
4. Follow the instructions in the console.
